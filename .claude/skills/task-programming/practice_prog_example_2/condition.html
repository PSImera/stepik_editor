Примитивные эмбеддинги: матрица совместной встречаемости

Теория

Идея, лежащая в основе Word2Vec: слова, встречающиеся в похожих контекстах, имеют похожий смысл. Самый прямолинейный способ закодировать это — построить матрицу совместной встречаемости.

Для каждой пары слов мы считаем, сколько раз они встретились рядом в тексте в пределах окна размером 1 (то есть непосредственно соседние слова). Каждая строка такой матрицы — это примитивный эмбеддинг слова: вектор, показывающий, с какими словами оно соседствует.

Затем, чтобы найти самое семантически близкое слово к запросу, мы сравниваем его вектор с векторами всех остальных слов по косинусному сходству и выбираем наиболее похожее.

Пример

Корпус:
кот спит
кот ест
собака ест

Словарь (все уникальные слова): ['кот', 'спит', 'ест', 'собака']

Матрица совместной встречаемости (окно = 1):
         кот  спит  ест  собака
кот       0    1    1     0
спит      1    0    0     0
ест       1    0    0     1
собака    0    0    1     0

Запрос: собака
Вектор собаки:   [0, 0, 1, 0]
Вектор кота:     [0, 1, 1, 0]
Вектор спит:     [1, 0, 0, 0]
Вектор ест:      [1, 0, 0, 1]

Косинусное сходство собаки с:
- кот:   (0×0 + 0×1 + 1×1 + 0×0) / (1 × √2) ≈ 0.7071
- спит:  0 / ... = 0.0
- ест:   (1×1) / (1 × √2)  ≈ 0.7071

Наибольшее сходство у кот и ест — при равенстве выбираем лексически первое: кот

Ответ: кот

Задание

Реализуйте функцию most_similar(corpus, query), которая:

  1. Принимает корпус в виде списка предложений (list[str]) и слово-запрос (str)
  2. Строит матрицу совместной встречаемости с окном размером 1 по всему корпусу
  3. Возвращает слово из словаря, наиболее похожее на запрос по косинусному сходству их строк в матрице (исключая само слово-запрос)

При равенстве косинусного сходства возвращайте слово, которое идёт первым в алфавитном порядке.

Словарь формируйте в алфавитном порядке — это обеспечит воспроизводимость результатов.

Примечание

Входные данные уже распарсены: corpus — список строк-предложений, query — строка. Вывод форматируется автоматически, вызывать функцию не нужно. Так же уже импортирована библиотека numpy как np
