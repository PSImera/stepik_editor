🔹 Артефакт – простой чат-бот с контекстом

📘 Описание задания

создайте простое консольное приложение, позволяющее пользователю общаться с чат-ботом, который помнит контекст беседы. По сути, это упрощенный вариант ChatGPT

Требования к функционалу:

  • Непрерывный диалог с пользователем: скрипт должен считывать ввод пользователя в цикле while с помощью input()), передавать его модели и печатать ответ. Затем снова ждать ввода – и так, пока пользователь не решит завершить и не напишет "выход"

  • Создайте агента с моделью "gpt-5"

  • Память диалога: бот должен помнить предыдущие реплики. Используем InMemorySaver()

Необходимые импорты уже произведены:

from langchain.agents import create_agent
from langgraph.checkpoint.memory import InMemorySaver

ничего импротировать больше не придётся
Раелизуйте код в функции Solution. Вызывать её не нужно

⚠️ Библиотеки в коде являются имитацией раельных библиотек в ввиду того что на платформе stepik нет возможности импортирования реальных библиотек. В имитированных библиотеках реализован лишь базовый функционал необходимый для этого задания.
